CSS Animations Showcase

Every animation, transition, and effect on this page is written in pure CSS. No JavaScript, no libraries, no frameworks. This demonstrates a deep understanding of CSS — the language of the web's visual layer.

Floating Orbs — CSS @keyframes + animation-delay
Each orb uses the same keyframe animation but with staggered delays, creating a wave effect from pure CSS.
