Project 02 — Network Security · Interactive Explainer

How HTTPS Actually Works

Most people know HTTPS is "secure" — but what actually happens during that connection? Click each step to walk through the TLS handshake process that protects every secure website you visit.

Networking Cryptography TLS/SSL Security
1
Client Hello
Your browser sends a "hello" message to the server. This includes the TLS version it supports, a list of supported cipher suites (encryption algorithms), and a randomly generated number.
→ Browser: "I support TLS 1.3, here are my cipher suites"
2
Server Hello + Certificate
The server responds with its chosen cipher suite and sends its SSL/TLS certificate — a digital document issued by a Certificate Authority (CA) that proves the server's identity.
← Server: "Using AES-256, here is my certificate"
3
Certificate Verification
Your browser checks the certificate against a list of trusted Certificate Authorities built into your OS and browser. It verifies the certificate hasn't expired, matches the domain, and hasn't been revoked.
Browser checks: Valid CA? ✓ Not expired? ✓ Domain match? ✓
4
Key Exchange
Using asymmetric cryptography (the server's public key), the browser and server negotiate a shared "session key" without ever transmitting it over the network. This uses Diffie-Hellman key exchange — mathematically clever.
Both sides derive the same session key independently
5
Encrypted Connection Established
Both sides confirm the handshake with a "Finished" message encrypted with the session key. All subsequent communication uses fast symmetric encryption (AES). The 🔒 padlock appears in your browser.
→ All data now encrypted with AES-256 symmetric key
6
What HTTPS Doesn't Protect
HTTPS encrypts the content of your communication but NOT the fact that you visited a site (your ISP still sees the domain), metadata, or what the website does with your data once received. It's transport security, not end-to-end privacy.
⚠ Your ISP still knows: you visited astontellis.github.io

Project 03 — Python · Data Processing Script

CSV Data Cleaner & Analyser

What It Does

A command-line Python script that takes any CSV file, cleans the data, identifies issues, and outputs a formatted summary report. Built to solve a real problem: raw data is almost always messy.

This directly connects to my Excel and SQL work — the same analytical thinking applied in a scripting context. It demonstrates that I can work programmatically, not just in spreadsheets.

Detects and reports missing values per column
Identifies duplicate rows automatically
Calculates basic statistics (mean, min, max, std dev)
Detects column data types and flags inconsistencies
Outputs a clean summary report as a .txt file
Works on any CSV — no hardcoded column names
Python 3 pandas Data Cleaning CLI Tool
↓ Download data_cleaner.py
Safe to download. This is a plain Python (.py) text file. You can open it in any text editor to read every line before running it. It requires Python 3 and pandas (pip install pandas). It only reads the CSV you point it at — it does not connect to the internet or access any other files.
data_cleaner.py 
# ─────────────────────────────────────────────────────
# CSV Data Cleaner & Analyser — by Aston Tellis
# Portfolio Project · Python 3 · pandas
# Usage: python data_cleaner.py your_file.csv
# ─────────────────────────────────────────────────────

import pandas as pd
import sys, os
from datetime import datetime

def load_csv(path):
    """Load CSV with encoding fallback."""
    try:
        return pd.read_csv(path, encoding='utf-8')
    except UnicodeDecodeError:
        return pd.read_csv(path, encoding='latin-1')

def analyse(df, filename):
    """Run full analysis and return report."""
    lines = []
    lines.append(f"CSV ANALYSIS REPORT")
    lines.append(f"File: {filename}")
    lines.append(f"Generated: {datetime.now()}")
    lines.append("-" * 50)

    # Shape
    lines.append(f"Rows: {df.shape[0]:,}")
    lines.append(f"Columns: {df.shape[1]}")

    # Duplicates
    dupes = df.duplicated().sum()
    lines.append(f"Duplicate rows: {dupes}")

    # Missing values per column
    lines.append("\nMISSING VALUES")
    for col in df.columns:
        missing = df[col].isna().sum()
        pct = missing / len(df) * 100
        if missing > 0:
            lines.append(
              f"  {col}: {missing} ({pct:.1f}%)")

    # Numeric column stats
    numeric = df.select_dtypes(include='number')
    if not numeric.empty:
        lines.append("\nNUMERIC COLUMN STATS")
        lines.append(numeric.describe().to_string())

    return "\n".join(lines)

def main():
    if len(sys.argv) < 2:
        print("Usage: python data_cleaner.py file.csv")
        sys.exit(1)

    path = sys.argv[1]
    df   = load_csv(path)
    report = analyse(df, path)
    print(report)

    out = path.replace('.csv', '_report.txt')
    with open(out, 'w') as f:
        f.write(report)
    print(f"\n✓ Report saved to {out}")

if __name__ == "__main__":
    main()

// Total Transaction Volume
Total Volume =
  SUMX(
    FILTER(Transactions,
      Transactions[Status] = "Completed"),
    Transactions[Amount])

// Month-on-Month Growth %
MoM Growth =
  VAR Current =
    CALCULATE([Total Volume],
      DATESMTD(Dates[Date]))
  VAR Previous =
    CALCULATE([Total Volume],
      PREVIOUSMONTH(Dates[Date]))
  RETURN
    DIVIDE(Current - Previous,
      Previous, 0)

// Fraud Flag Rate
Fraud Rate =
  DIVIDE(
    COUNTROWS(FILTER(
      FraudFlags,
      FraudFlags[Status]="Confirmed")),
    COUNTROWS(Transactions), 0)
